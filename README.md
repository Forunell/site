Portfolio

Personal portfolio with five project case studies: FormaStore, DealPilot, BookNest, FlowDesk Bot and DataForge.

Built with HTML, CSS and JavaScript. Includes responsive project cards, light and dark themes, category filters and image galleries.

## Local preview

Run `python -m http.server 8080` from this directory and open http://localhost:8080.

## GitHub Pages

The website files are ready to serve from the repository root. In repository Settings > Pages, select the publishing branch and the root directory.

Project demos are local; public demo links are not configured.
